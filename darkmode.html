On Reading at Night

A theme that follows the light, or lets you choose your own.

This page ships with two moods: a warm, paper-toned day edition and an ink-dark night edition. Flip the dial in the header and every color, border, and shadow eases across in a fraction of a second — no page reload, no flash.

Your preference is remembered the next time you visit, using localStorage. If you've never chosen one, the page quietly follows your system's setting instead, and updates live if you change it while this tab is open.

How it's wired

A single data-theme attribute on the <html> element switches a set of CSS custom properties. JavaScript only toggles that one attribute and saves the choice — the rest is CSS doing the work.
