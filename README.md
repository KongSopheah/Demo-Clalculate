# 🧮 Calculator with Dark Mode

A simple and modern calculator built with **HTML, CSS, and JavaScript**, featuring a clean user interface and **Dark Mode**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal calculations
- 🧹 Clear / Reset
- ⌫ Delete / Backspace
- 🌙 Dark Mode
- ☀️ Light Mode
- 📱 Responsive design
- 🎨 Modern calculator UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## 📂 Project Structure

```text
md/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🌙 Dark Mode

The calculator supports both **Light Mode** and **Dark Mode**.

Users can switch between the two themes using the Dark Mode toggle/button.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/KongSopheah/Demo-Calculate.git
```

2. Open the project folder:

```bash
cd Demo-Calculate
```

3. Open `index.html` in your browser.

You can also use **Live Server** in VS Code to run the project.
